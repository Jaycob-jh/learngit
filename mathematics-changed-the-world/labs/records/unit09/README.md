### 失败案例与边界

- **A：参数选择与可辨识性。** 早期探索曾用 $\lambda=0.015$，基线相对恢复误差约 0.779，即使 prox mapping 近零也没有良好恢复。该轮原始证据保留在本地 `Unit09-runs-2026-09-27/`；之后改为 $0.002$。最终压力实验在同一种子、相同观测噪声下只改变一列以制造近共线；因此可将上述差异归于本次矩阵扰动，但不能据单次合成数据推断一般恢复概率。
- **B：特征尺度失衡。** `--stress` 将一列特征乘以 100。它改变优化几何，也改变固定 $\ell_2$ 惩罚对原始尺度的相对作用，因此本次差异不能仅归因于数值条件数。准确率与损失/最优性指标给出不同信息。
- **C：欠采样与噪声联合压力。** `--stress` 同时将观测数从 240 降至 24、噪声标准差从 0.02 增至 0.3；这是联合失败条件，不能分辨两因素各自的贡献。符号等价误差 $\min(\|x-x^*\|,\|x+x^*\|)/\|x^*\|$ 适用于本实数模型，不能直接推广到复数相位等价类。

上述观察只覆盖一个种子、给定模型与固定迭代预算。实验脚本的停止条件不是统一精度门槛；脚本退出码 0 只表示运行完成，不等于数学或应用性能验收。

# 时间线与现实应用地图

## 历史时间线

| 时期 | 关键变化 | 代表人物/事件 |
|---|---|---|
| 古代 | 演绎几何、穷竭法、素数 | Euclid、Archimedes |
| 16–17 世纪 | 代数符号、解析几何、复数 | Cardano、Bombelli、Descartes、Fermat |
| 1660s–1680s | 微积分形成 | Newton、Leibniz、Barrow 等 |
| 18 世纪 | 分析、级数、ODE、概率 | Euler、Taylor、Bernoulli、Lagrange、Laplace |
| 1800–1850 | Fourier、复分析、非欧几何 | Fourier、Cauchy、Gauss、Lobachevsky、Bolyai |
| 1850–1900 | 矩阵、群论、Riemann 几何、解析数论 | Cayley、Galois、Riemann、Hadamard |
| 1900–1930 | 测度、Lebesgue 积分、函数空间 | Lebesgue、Borel、Hilbert |
| 1930–1950 | 可计算性、概率公理、信息论 | Turing、Church、Kolmogorov、Shannon |
| 1950–1970 | 数值计算、FFT、控制、现代统计 | 数字计算机与算法化数学 |
| 1960s–今天 | 混沌、优化、机器学习 | Lorenz、现代计算数学 |

## 三次抽象升级

### 从量到函数
运动、热、波、物理状态都可以写成函数，再做微分、积分和展开。

### 从函数到结构
19 世纪以后，群、矩阵、流形、拓扑、函数空间本身成为研究对象。

### 从结构到信息与算法
20 世纪开始，“能不能算、需要多少比特、算法多快、数据怎样更新概率”也成为数学对象。

## 四个跨行业数学动作

1. 变换：把问题搬到更好算的空间。Fourier、Laplace、SVD 都是典型。
2. 线性化：在局部先用简单模型。Taylor、Jacobian、Hessian。
3. 概率化：承认信息不完整。Bayes、随机过程、统计估计。
4. 离散化：把连续世界交给计算机。有限差分、有限元、有限体积、FFT、数值积分。

理解应用时，最好记住这些“动作”，而不是只记某行业用了某条公式。

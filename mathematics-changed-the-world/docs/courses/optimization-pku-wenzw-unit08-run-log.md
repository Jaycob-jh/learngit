## 解析参考与预设失败

脚本使用 $8\times8$ 对称矩阵，其预设特征值从 $0.5$ 到 $8.0$。球面最小值为 $0.5$；Stiefel 的 $p=2$ 最小值是最小两个特征值之和。最大特征子空间是驻点但不是最小子空间，因此固定在该点的切向梯度可能为零而目标非最小。此判断需要用实际输出检查，而不能由脚本存在代替。

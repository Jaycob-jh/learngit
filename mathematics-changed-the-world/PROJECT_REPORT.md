## 1. 项目背景

本项目起源于一段以“九个经典数学公式/定理”为线索的短视频。最初的目标是识别视频中的九个数学主题，并解释它们“为什么重要”。

在后续讨论中，项目目标被扩展为两条并行主线：

1. 将九个核心数学主题做成真正可学习的专题资料，包括前史、关键人物、发展过程、公式原理、现实应用、常见误解和实验；
2. 不局限于九个主题，继续扩展到现代数学与科技的主要知识主干，使整个项目逐渐成为“数学思想史 × 现代科技知识图谱”。

项目最终形成了一个面向长期维护的中文数学知识库，而不是一组孤立的公式笔记。

## 7. 数学公式渲染专项修复

2026-09-19 晚间进行了一次全项目数学公式渲染专项修复。

### 原问题

部分 Markdown 使用：

```text
\( ... \)
\[ ... \]
```

在某些 GitHub/MkDocs 页面中没有被正确识别，导致页面直接显示 LaTeX 源码。例如：

```text
[ A(x)=\int_a^x f(t)\,dt, ]
```

以及 `\frac`、`\int` 等命令直接显示为文本。

### 修复标准

统一为：

- 行内公式：`$...$`
- 独立公式：`$$...$$`

例如：

```markdown
若 $f$ 连续，定义

$$
A(x)=\int_a^x f(t)\,dt.
$$
```

### MathJax 配置

新增：

```text
docs/javascripts/mathjax.js
```

并在 `mkdocs.yml` 中显式加载 MathJax 配置和 MathJax 3。

### 全仓检查结果

最终对 **40 个 Markdown 文件**进行了公式语法扫描，检查内容包括：

- 遗留的 `\[` / `\]`；
- 遗留的 `\(` / `\)`；
- 错误的单独 `$` 块；
- 数学环境外裸露的 `\frac`、`\int`、`\sum`、`\nabla`、`\mathbb` 等 LaTeX 命令。

最终扫描结果为：**未发现上述残留问题。**

## 8. 内容质量原则

项目当前采用以下内容原则：

### 不采用“单一天才神话”

微积分、散度定理、Bayes 推断等理论都强调前驱、并行发展和后续严格化，而不是简单归功于一个人。

### 区分数学对象、算法和实现

例如：

```text
Fourier transform ≠ DFT ≠ FFT
attention 数学定义 ≠ GPU kernel 实现
概率定理 ≠ 具体统计模型
```

### 区分“数学联系”和“直接工程应用”

例如 RSA 使用大素数，但不能简单写成“RSA 直接应用素数定理”。

### 公式必须回到问题

每个重要公式都应回答：

1. 为什么当时需要它？
2. 它把什么困难问题换成了什么表示？
3. 它的适用条件是什么？
4. 现实系统中究竟在哪一层使用？

# 数学如何改变世界：从九个经典公式到现代科学

这是一个中文数学思想史/应用知识库。项目从“九个经典公式”出发，但不把数学史写成天才名单，而是追问：

1. 一个理论出现之前，人们遇到了什么难题？
2. 它由哪些前驱、关键人物和严格化过程共同形成？
3. 它带来了什么新的表示方法或计算能力？
4. 它今天在物理、工程、通信、医学成像、统计、AI、密码学中究竟做什么？

## 九个核心入口

| # | 主题 | 核心思想 | 现实落点 |
|---|---|---|---|
| 1 | 微积分基本定理 | 局部变化 ↔ 整体累积 | 力学、控制、优化、PDE |
| 2 | Taylor 展开 | 局部用多项式逼近复杂函数 | 数值计算、误差、优化、微扰 |
| 3 | Euler 公式 | 指数、旋转、复数、三角函数统一 | 交流电、波、量子、信号 |
| 4 | Fourier 变换 | 时空域 ↔ 频域 | 通信、音视频、MRI、光学 |
| 5 | 散度定理 | 内部源汇 ↔ 边界通量 | 电磁、流体、守恒律 |
| 6 | 留数定理 | 全局积分由奇点局部信息控制 | 实积分、逆变换、系统理论 |
| 7 | Bayes 公式 | 新证据到来后更新概率 | 统计、诊断、AI、传感器融合 |
| 8 | 对数积分与素数 | 局部无序背后的宏观规律 | 解析数论、素数分布 |
| 9 | Lebesgue 单调收敛 | 极限什么时候能穿过积分号 | 概率、Fourier、PDE |

## 不止九个

项目继续延伸到：复数、线性代数、微分方程、非欧几何、群论与对称性、信息论、可计算性、混沌、凸优化与机器学习。

## 核心观点

数学改变世界，往往不是因为某个公式“神奇”，而是因为它创造了一种新的表示语言：把运动表示成导数，把复杂函数表示成局部多项式，把信号表示成频率，把不确定知识表示成概率分布，把对称性表示成群，把算法本身变成数学对象。
